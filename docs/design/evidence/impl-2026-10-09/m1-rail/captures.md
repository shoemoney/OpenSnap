## How this set was made

- `sh tools/eye-dump-audit.sh --groups pairs,sizes,fullscreen,states --appearances light,dark --icons both` at source `fef46c7` (clean tree). The harness is the only capture path: throwaway bundle id, sandbox, real-store guard (stores unchanged, see `safety.txt`), cleanup before the final compare. No `original/` fixtures; every shot is the synthetic gradient-and-fake-windows fixture.
- **FA unavailable:** no FontAwesome subset fonts are bundled in this build, so `--icons both` ran `sf` only and recorded `fa` as unavailable (`manifest.json` → `unavailable`, `faMode`). Nothing is faked.
- Each PNG is the one stored copy, scaled to at most 1200 px wide (so 980 pt windows are shown at about 0.61 of their native 2x pixels). Native pixel size is in `manifest.json` (`pixelSize` vs `storedPixelSize`).
- `layout/<stem>@fef46c7.json` beside each editor capture is the per-capture metrics file: per-group frames of both bars, gaps, free width, status width with and without the Original-size checkbox, viewport rect and trailing margin, canvas centring, Frame hole vs capture rect, and `"rail": "absent"` (neither retired group id exists, trailing margin is 12 pt, no narrow view parked on the trailing edge). **All 80 layout files say `rail: absent` with a 12 pt trailing margin and no overlapping groups.**
- Matrix content: `S11E` = the blank 800×600 canvas (empty); `S11M` = a 1200×800 synthetic shot with every annotation kind (populated, 2400×1600 output, so the Original-size checkbox is visible); `S11F`/`S11FP` = true full screen, empty / blank canvas plus annotations. `full` in the matrix is the display's visible frame (2056×1197 here), not true full screen.
- BEFORE column: the pre-change twin at `dc1eb26` in `docs/design/evidence/2026-10-09/`, by path. Captures with no honest twin show `—` (new surfaces, the populated matrix, 1280 Frame).
